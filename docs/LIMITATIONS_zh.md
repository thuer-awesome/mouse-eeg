# 限制与待交接事项

- ADC 到微伏的绝对标定没有确认，不能把 a.u. 数值解释成跨设备绝对幅值。
- 任务一 corrected decoder 只重解码冻结概率，没有重新训练权重；事件边界改善不能被写成模型性能提升。
- 任务一外部候选需临床 adjudication；precision 低不等同于所有候选都是真误报。
- 居中 21 窗 Physio 上下文和零相位滤波带来离线优势，也带来严格实时不可直接复用的延迟/非因果问题。
- PG36 是探索性形态标签，存在鼠特异类别和低置信度事件，不能直接映射 ILAE 临床分类。
- 当前没有硬件采集 SDK、LSL/TCP/UDP 流接口、在线因果滤波验证、断流/时钟漂移测试或医生修改审计数据库。
- GitHub 推送前需确认原始数据和衍生图集的伦理、隐私及机构许可；仓库未获得远程认证时不得声称已发布。
