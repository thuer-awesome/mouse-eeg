# 临床复核说明

PDF 中每页只显示一个独立通道和一个连续记录片段：上面是滤波 EEG，中间是窗口概率，下面是连续解码状态。蓝色半透明区间表示输入的人工事件；橙色边框表示模型预测区间。页面标题含动物、记录、通道和时间范围，便于回到原始文件核对。

`full`、`partial`、`low`、`missed` 只描述当前人工事件的时间覆盖。`label_external_prediction` 表示预测区间与当前标签零时间重叠，不等价于已确认误报，可能是漏标或边界差异。医生复核应记录接受、拒绝、合并、拆分和起止点修订，而不是只看窗口 accuracy。

输入无人工标签时，PDF 仍可展示候选和概率，但不能得出灵敏度、精确率或漏检结论。当前 CLI 是离线/回放原型；连接图机前必须另行实现因果滤波、环形缓冲、时间同步、断流策略和操作审计。
