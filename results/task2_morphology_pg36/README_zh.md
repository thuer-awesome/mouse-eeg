# PG36 形态学多分类正式结果

本目录只包含冻结的 pooled PG36 lineage。每个事件×有效通道是一个独立观察；PG 类别是探索性形态类别，不是临床发作亚型。`classification/all_window_model_comparison.csv` 是全部测试窗口主结果，不能用 capped-at-8 敏感性表替代。历史 taxonomy 不属于此正式入口。

重要对齐限制：PG36 使用自身的事件划分（6,393/1,375/1,376），与任务一严格 protocol（4,495/960/957）不同；测试键完全一致的只有 111/1,376，另有 642 条 split 不一致、591 条缺失。因此这里是形态探索快照，不能作为任务一严格跨域泛化结果，也不能与任务一指标合并。
